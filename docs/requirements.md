2026-10-02，根据原项目文档和用户本次重构授权提炼。本文件是叁序需求入口；界面根据用户反馈继续迭代，不将功能通过视为视觉设计获得认可。

## 产品与交付

叁序面向熟悉福彩3D、习惯自行选择号码的用户。主流程为：看开奖/走势 → 选择选号方式 → 加入本期 → 调整与记录 → 开奖核对。

独立目录 D:\codexproject\SanXu，应用标识 com.sanxu.app，名称叁序，当前重设计版本1.0.2/3。Lucky3D目录和已安装应用保留；两应用独立存储，不提供旧库升级或导入。交付源码、测试APK和实际验收证据，不自动公开发布。1.0.0及其原型留作历史，当前视觉以当前设计规格和Android实装截图为准。

## P0 日常选号

| 编号 | 能力 | 验收 |
|---|---|---|
| P01 | 首层单选、组选、单选单、位选四入口 | 首屏可见，进入后立即操作，无前置筛选表单 |
| P02 | 单选逐注录入 | 007为一注；只接受三个ASCII数字，重复输入在本次内部去重 |
| P03 | 组三/组六数字池或按注输入 | 组三池012产生001/002/011/022/112/122；组六0123产生4注 |
| P04 | 单选单 | n个不同数字生成n(n-1)(n-2)个有序、三位不同号码 |
| P05 | 位选 | 按百/十/个位逐步选择，只展开当前位；三位置集合有序组合；任一位置为空则不生成；满池1000注 |
| P06 | 固定汇总与加入本期 | 号码数、1—99倍、金额可见；不强制标题/备注；只有持久化成功才反馈 |
| P07 | 草稿恢复 | 各方式独立，保存期号、输入、倍数、剔除、条件；切页/重启可继续 |
| P08 | 号码明细 | 数量大时单独浏览，支持剔除和恢复；主操作不被列表挤出屏幕 |

## P0 按期清单

合并键是期号、正式玩法、规范化号码。单选/单选单/位选均为单选；组选3/6排序规范化后合并，正式玩法之间不合并。每次来源内部去重，跨来源倍数相加；累计倍数允许超过99。

每个来源保存完整输入和候选快照。合并清单由来源计算，编辑、删除、撤销只改变相应贡献。一次加入中的重复必须弹窗说明，自动完成合并，提供撤销；按钮忙态和操作ID防止连击/失败重试重复累计。

金额=所有有效号码累计倍数之和×2元。号码数与含倍数注数分别标注。例：012×2加上012单选单六注各1倍，结果6个号码、8注、16元，012为3倍。

本期/往期分区，支持备注、来源编辑、删除和复制到新一期。已开奖记录锁定原始选号，复用先复制到新一期。核对以正式开奖号为准，显示包含/未包含及匹配号码；官方修正更新核对，保留原始来源。

目标期可修改。建议期号只来自近期连续开奖；跨年或旧数据不可靠时保持未绑定，要求填写/选择期号。已经开奖的期号不能新增或改写正式清单。

## P1 分析与内容

- 首页：最新结果、常用属性、试机号、最近五期对齐表与本期摘要；期号详情保留逐位置开奖前遗漏/冷热和云南公告。正常手机首屏显示全部核心内容。
- 走势：10/30/60/100期，完整位置和和值0—27及属性列，统一缩放/横纵移动，两期待开奖行和四行统计；快捷定位和数字带入位选。
- 二级工具：条件筛选、胆码/拖码、模板、历史回测。模板存条件及观察窗口，回测仅使用目标期之前的数据，缺样本不计分母。
- 彩报：牛彩网A11第三版，最近30个北京时间自然日换期、缩放、失败重试；无收藏/分享/下载按钮。
- 设置：主题、应用内提示及本地数据状态；不提供账号、支付、后台准点推送。
