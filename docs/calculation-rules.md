# 叁序计算口径 · 规则版本 1

## 号码与玩法

所有号码使用三个 ASCII 字符，保留前导零。单选按百、十、个位排序匹配；组三恰好两个相同数字，组六三个不同数字。组选规范号升序排列。豹子只参与单选。

| 选号入口 | 生成方式 | 正式核对玩法 |
|---|---|---|
| 单选 | 逐注或批量录入三位号；本次输入去重 | 单选 |
| 组选 | 组三数字池产生两同一异，组六池取三个不同数字；也可直接录入合法号码 | 组三 / 组六 |
| 单选单 | 从 n 个不同数字中生成 n×(n−1)×(n−2) 个有序号码 | 单选 |
| 位选 | 百位集合×十位集合×个位集合 | 单选 |

满池单选/位选为1000注；单选单720注；组三90注；组六120注。组三池012为001、002、011、022、112、122；组六池0123为012、013、023、123。

条件之间取交集，组内“允许集合”取或。筛选在当前入口生成的合法集合上运行，再剔除用户排除项。胆拖的胆码与拖码互斥；组三1胆起，组六最多2胆，具体冲突由NumberPool返回。

## 注数、合并与金额

来源内部去重。按期号、正式玩法、规范号码合并，跨来源倍数相加。每个来源1—99倍，合并后可以超过99倍。编辑、删除、撤销只影响一个来源的贡献。

号码数 = 合并后的键数量；注数 = 每个合并号码倍数之和；金额 = 注数×2元。全部汇总使用Long精确加乘，不用浮点金额。

黄金案例：单选012×2，加单选单数字池012×1，得到6个号码、8注、16元，其中012×3。再加组六012×1，得到7个号码、9注、18元，组选与单选分别保留。

核对显示匹配号码与含倍数命中注数，不计算未确认的奖金、收益或未来概率。已开奖期禁止新增、修改、删除；复制会产生新来源。官方修正后直接从当前正式开奖号重新核对。

## 属性、遗漏与冷热

和值=a+b+c；和尾=和值模10；跨度=max−min。0为偶数；5—9为大数。项目质合习惯口径“质类”为1、2、3、5、7，“合类”为0、4、6、8、9，此定义不是数学素数定义。

012路按数字模3；位置型分别记录三位所属路，个数型统计各路数量。连号按去重后的排序数字是否相邻。重号是前后两期数字集合交集，邻号为上一期数字±1（不循环到0/9）与本期集合的交集。

当前遗漏为距离最近一次命中的连续未出现期数。命中当期显示0；从历史起点从未出现时，按已观察期数累计。平均/最大遗漏只使用两个命中之间的完整间隔；没有完整间隔时显示空值，不把未知当0。

首页“开出前”先排除最新开奖再计算，避免把本期刚开出的数显示为遗漏0。冷热观察30期：位置数字期望出现数=窗口期数/10，实际/期望<0.8为冷，<1.2为温，其余为热。标签同时保留实际次数。

## 历史回测

当前输入和筛选生成固定候选，逐期按1倍核对；每期模拟金额=候选数×2。回测展示最近30/100/300个可评估目标期，每个目标至少需要其前30期样本。缺样本不进入分母。目标期之后的数据不传入生成器。

覆盖率=覆盖期数/可评估期数。回测不会自动调整条件，不代表预测或未来中奖概率。试机号和彩报不进入这一计算链。
