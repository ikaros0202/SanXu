# 叁序整体体验与页面设计 · 第二轮

2026-10-02。用户否定上一轮视觉与空间组织，本规格替代旧稿；原功能验证不能作为新设计验收。

## 整体构思

把应用组织为一本可操作的数字记录簿。每天查看开奖与近期数据，在一块完整的选数面板内输入，最后把不同思路汇入同一期记录。各屏幕共享三层：紧凑页头和上下文、连贯的内容区域、必要时出现的任务操作栏。

按钮属于内容：期号切换归入上下文栏，批量/清空归入输入区，明细归入结果区，来源编辑归入对应记录。禁止在内容间单独铺一行短按钮，禁止为一句解释新增大卡片，禁止每个控件都成为独立视觉块。通过分组、同行排列和按需展开提升密度，保留48dp触控目标。

## 统一视觉

冷白纸面、深蓝墨色和低饱和蓝色选中态；强调色集中在当前选择和主要动作，错误为红色。取消大面积红色数字键、巨型导航选中胶囊和强阴影。

浅色背景#F3F5F8、纸面#FFFFFF、正文#1B293C、主色#345A87、弱面#EDF1F6、边界#DCE3EC。深色背景#101722、纸面#192331、正文#E7EDF7、主色#B4CDF2、弱面#222E40。两种主题分别检查。

页头56dp；导航内容64dp加系统安全区；左右边距16dp；组内4/8/12dp，组间16dp；内容面板18dp圆角，控件8/10dp，状态标签6dp。标题22sp、区块15/16sp、正文14sp、说明12sp；号码等宽；开奖号44sp，其余数字按任务层级设置。

## 页面结构

| 页面 | 内容与操作的组织 |
|---|---|
| 首页 | 紧凑品牌栏；开奖面板内含期号/刷新、整组三位号、属性、云南公告入口；试机号明确独立标识；位置回顾合成表；本期方案摘要携带操作；点期号进入详情与历史档案 |
| 选号 | 点选上下文期号才展开编辑；四方式使用连接式切换栏；号码、批量、清空和说明属于同一面板；明细在面板页脚；底部把金额、倍数、加入/更新放在同行 |
| 方案 | 未开奖/已开奖与期号集中；金额、号码数、含倍数注数统一摘要；号码与来源切换查看，避免长页堆叠；编辑与更多菜单归属来源 |
| 走势 | 期数选择和说明归入页头；保留全表；快捷定位为一条连续工具栏；选点后出现带入位选的操作条 |
| 彩报 | 页头带刷新；前期、期号、后期、缩放比例为一条阅读工具栏；缩放细项按需展开，图片为主体 |
| 选号工具 | 筛选/模板/备注分区；范围、玩法、条件在同一工作面板；添加在区块标题右侧；完成固定底部；模板保存/应用与方法关联 |
| 号码明细 | 保留数与恢复同行；均匀多列号码矩阵，以勾选和颜色表达选择 |
| 历史回测 | 期数与方法信息集中；三项统计同一摘要；逐期结果固定列对齐 |
| 档案与详情 | 搜索与总期数合并；期号/日期/号码对齐；详情把属性与公告分组，长内容滚动 |
| 设置 | 三种主题同行；开关同行；同步状态与刷新同行；说明保持低强调 |

## 行为与状态

保留计算与存储口径、前导零、独立草稿、按期合并、来源修订和撤销、开奖锁定、离线保留。保存反馈把期号、结果和继续/查看/撤销组织为一体。取消期号弹层不覆盖原输入。错误归入对应内容，重试保持原位置。空页说明缺少什么和下一步。

393×851dp基准：位选三个位置、明细入口、金额、倍数、保存和导航无需滚动。360×800dp同样检查核心控件可见，位选在面板内预览4个组合，完整号码列表独立滚动。检查1000号码池、200字备注和40字模板名称；列表中模板标题最多两行，点行查看完整标题。

## 实装验收

- 每个小操作有明确所属内容，没有无缘由的独立短按钮行。
- 相同任务不跨无关联卡片；面板内部用细分隔线表达层级。
- 页头、上下文、字号、导航基线一致；选择状态除颜色外有形状、下划线或勾选。
- 位选首屏、保存反馈、期号与来源编辑实际操作通过，不压缩触控范围换空间。
- 五个主页面和全部二级页面保留实际截图；彩报截图不包含第三方原图，真实图片另做功能测试。
- 大小手机、深浅色、空/失败/长内容分别记录；构建通过不能替代视觉验收。

使用ui-ux-pro-max原生Compose指南和design-qa-checklist；检索中的网页Hero/CTA与粉色配色不适用本应用。遵守禁止使用oiloil-ui-ux-guide和wireframe-spec的要求。
