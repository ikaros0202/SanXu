# 叁序视觉与交互规格

## 品牌

叁序：三个数字，各有次序。标识采用三枚错位数字点与序列线的矢量图形。应用整体是温暖、准确、易读的工具；页面围绕用户当前动作组织。

## 视觉

浅色：背景#F6F4EF，表面#FFFFFF，文字#222725，朱红#B43C32，次级文字#626A64，边界#DCDDD4；深色：背景#151B19，表面#202823，文字#EEEFE6，朱红#FFB4A9，边界#465148。

强调色用于当前操作和号码，正文保持墨色。采用4dp节奏、16dp页面边距、12/16dp圆角，有限的24dp主视觉圆角。普通分组优先细分隔线。标题24sp、正文16sp、说明12—14sp、开奖48sp，号码用等宽字体。

图标统一Material轮廓；按钮48dp以上。界面仅使用任务、内容与状态文案。动效120—220ms。跟随系统深浅色并允许用户指定主题。

## 页面

- 首页：品牌及设置 → 当前期号与三位大数字 → 常用属性 → 逐位置回顾 → 云南公告 → 试机号/刷新 → 本期清单摘要。详情通过期号进入，日期只作为元数据。
- 选号：标题/期号 → 单选、组选、单选单、位选四标签 → 相应编辑区 → 明细/进一步筛选 → 固定号码数、倍数、金额、加入按钮。每个数字选择区域五列两行，位选三个位置分别标明。
- 方案：本期/往期 → 数量与金额 → 玩法分组的合并号码 → 选号记录。原始来源可以编辑或删除，已开奖时只允许复制新一期。
- 走势：精简标题与期数 → 快捷定位 → 全表统一viewport。数字、落点、连线、非颜色标记保留；期号列与全部内容一起移动。
- 彩报：标题/版次 → 期号与上/下期 → 图片。图片手势区域与换期控制分开。
- 工具：条件筛选、胆拖、模板、回测为二级页面，显示当前作用范围，不干扰日常四入口。

## 状态与反馈

空选号显示一句必要说明；未完整禁用加入。保存期间按钮忙态。成功后可以继续选号，重合时弹窗列出数量与变化，提供撤销。存储错误保留输入并提供重试。无网保留已加载内容。对已开奖期的写入明确拒绝。新期号不可靠时保留草稿，让用户指定目标期。

正常核心内容在393dp基准手机整屏可达；360dp检查不截断，明细列表可以滚动。底部汇总不得覆盖列表或系统导航区。数值前导零、长备注、1000注最大集合、空数据和失败状态都要检查。

## 设计研究使用范围

使用ui-ux-pro-max的Android交互检索：原生48dp目标、输入与业务状态分离、明确反馈、文字/数字层级、深浅色检查。检索产生的网页营销布局、英文衬线字体和自然绿色建议不适用本项目，采用已确认的叁序设计方向。没有使用oiloil-ui-ux-guide或wireframe-spec。
