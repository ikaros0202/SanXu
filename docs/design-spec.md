# 叁序视觉与交互规格 · 1.0.2

> 本文只保留1.0.2历史实现。顺序选号与大组件已被用户否定；本轮按五张页面参考写入新 UI 源码，尚未编译测试。当前约定见 [design-next.md](design-next.md)，代码设计值见 [DESIGN.md](../DESIGN.md)，下一步见 [代码交接](implementation-number-studio.md)。旧步骤、尺寸和验收结果不能覆盖最新决定。

2026-10-02的1.0.2实现阶段：用户当时选择B纵向位选和开奖号优先首页，并要求加强配色、缩小组件、提高一屏信息量。本规格记录其替代1.0.1蓝色视觉的实现，随后B流程与组件密度又遭否定；保留记录用于回归和理解旧代码，不用于指导新的构图。

## 整体组织

首页看开奖，选号分步输入，方案按期整理。五个主入口不变。每个小操作依附自己的内容：期号旁清空，步骤内全选与下一位，结果旁明细，来源行内编辑，页头提供全页工具。正文不堆开发背景，不单独为短按钮放大块面板。

## 主要页面

| 页面 | 一屏任务与层级 |
|---|---|
| 首页 | 紧凑酒红页头；约144dp开奖区域，三位号/属性/期号/刷新；56dp试机号；最近五期的对齐表；方案摘要和开始选号合并为64dp操作行。错误提示归入开奖块。云南公告、开奖前遗漏与冷热移入当期开奖详情 |
| 选号 | 四种方式48dp页签；48dp期号上下文；B纵向步骤只展开当前位。每位48dp标题行、当前位104dp数字键区及48dp操作行。其他位显示已选摘要。组合预览和明细就近；金额、倍数、加入/更新固定底部同行 |
| 方案 | 未开奖/已开奖与期号同行；紧凑浅红摘要显示金额、号码数、注数、来源数；合并号码/来源记录切换。号码按三列排，来源行内编辑或更多，底部继续选号 |
| 走势 | 酒红页头带期数和说明，连续快捷定位栏；图表占剩余空间，保留完整数字、属性、遗漏及非颜色编码；选点后显示用于位选操作 |
| 彩报 | 页头带刷新，换期和缩放同行；图像占其余区域。加载/错误/重试保持当前位置；第三方原图不进源码、APK或验收截图 |

## 二级页

筛选/模板/备注使用同一平面页签；条件、保存、应用与所属内容同组。号码明细使用多列48dp可选格。回测为三项摘要与对齐表，禁止图形夸大结果。开奖档案列表56dp行，详情保留属性、开奖前回顾和云南公告。设置64dp行并使用“浅色/深色”直白主题名称。

## 状态与数据

加载使用局部进度，空内容说明下一步，失败保留原数据与重试；正式开奖失败显示最后成功时间。方案保存提供撤销、继续、查看；来源修改保持修订和开奖锁定。Activity重建后保留当前位与所有数字；切换位置只改变展开区域。满池1000号码不扩展页面高度，完整结果进入明细。

首页回顾的数据始终截断在被查看期之前，不读取未来开奖。正式开奖、试机号、公告、彩报互不推断。本轮不修改领域规则、数据库结构或种子数据。

## 验收

360×800dp和393×851dp，两种主题；正常首页第五行与开始选号同屏；位选保存和明细同屏，只有十个数字键存在；控制48dp；000/007保留；1000号码、200字备注、40字模板、错误、空、取消、更新、撤销、进程恢复均覆盖。构建通过不能代替截图检查，也不宣称用户已经认可最终审美。
